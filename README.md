# 📚 BIT_learning 项目

## 📖 项目简介

**BIT_learning**
整理了部分北京理工大学学习资料，主要包含一些学科的电子教材、课程笔记作业、习题及参考答案等学习资源（资料来源于网络与个人，仅用于学习交流）。

* 信息科学技术
* 网络空间安全

## 📂 项目目录结构（示例）

本仓库按学期和年级组织资料：

- 大一上：大学计算机基础、工科数学分析 I、思想道德与法治
- 大一下：C 语言、工科数学分析 II、大学物理、电路分析基础、近代史纲要、通用学术英语

持续更新ing
